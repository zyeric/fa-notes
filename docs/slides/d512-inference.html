Why d changes the balance

MMA 随 d 增长；softmax 随 score tile 增长

QK ≈ 2 Bᵣ B𝚌 d_qk PV ≈ 2 Bᵣ B𝚌 d_v softmax ≈ O(Bᵣ B𝚌)
d 128 → 512→MMA work ≈ 4×|score count unchanged
更贵，但更容易把 Tensor Core 喂饱。
  • softmax / barrier / address work 更易 amortize；
  • MQA KV reuse 才是更强的 FLOP/byte lever；
  • d 自己同时增加 bytes 与 FLOPs；
  • resource cliff 可能抵消收益。
