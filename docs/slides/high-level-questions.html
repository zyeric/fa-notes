Attention · mathematical contract

优化的是 schedule；forward / backward 的函数先固定下来

FORWARD
α = 1 / √d S = α Q Kᵀ # [N,N] P = softmax_row(S) # [N,N] O = P V # [N,d]

Forward：tile 内短暂生成 S/P；online softmax 只跨 K/V tiles 保留 m,l,O。

FlashAttention 改 IO schedule，不改变 exact attention。
BACKWARD · G = dO
# reconstruct forward probability tile S′ = α Q Kᵀ P′ = exp(S′ - LSE[:,None]) dV = P′ᵀ G dP = G Vᵀ D = rowsum(G ⊙ O) dS = P′ ⊙ (dP - D) dQ = α dS K dK = α dSᵀ Q

Backward：S′/P′ 是重算值，不是保存的 N×N tensor；mask、scale 与 dropout RNG 必须按 forward contract replay。

Warp specialization · software decomposition

先把一个 CTA 内的 warps 分成长期角色，再用 barrier/pipeline 交接数据

role = warpgroup_id(threadIdx.x) if role == TMA_PRODUCER: load K/V into circular SMEM stage signal stage_ready elif role == MMA_SOFTMAX_CONSUMER: wait(stage_ready) issue WGMMA; run softmax signal stage_released else: epilogue / tile scheduler

这是 conceptual skeleton；实际 FA3 source 用 warp/warpgroup ID、pipeline state 与 named/transaction barriers 实现。

ROLE BRANCH

整个 warp/warpgroup 走同一条 uniform branch；producer 不需要执行 consumer 的矩阵与 softmax loop。

HANDOFF

mbarrier/pipeline state 表达“buffer 已填好”和“consumer 已释放”；SMEM lifetime 因此可证明。

RESOURCE BUDGET

setmaxnreg 可把 producer 不需要的 register budget 让给 consumer；但整个 CTA 仍共同 residency。

FA1 的根问题：不要把 N² score / probability 往返 HBM

数学没变；dataflow 变了。

  • Q/K/V 分块进入 on-chip SRAM；
  • online softmax 用 (m,l,O) 压缩已经看过的 score history；
  • backward 重算 S/P，而不是从 HBM 读完整 N² 中间量。
FA1 是 exact attention 的 IO-aware schedule，不是 approximate attention。

FA1 / FA2 · backward ownership

一个 K/V-tile CTA 完成 dK/dV；很多这样的 CTAs 共同写同一个 dQ

FA2 SEQUENCE-K MAIN KERNEL
CTA J fixes K_J, V_J for every valid Q tile I: P_IJ, dS_IJ = recompute(...) acc_dV_J += P_IJᵀ dO_I acc_dK_J += dS_IJᵀ Q_I partial = dS_IJ K_J atomicAdd(dq_accum[I], partial) store final dK_J, dV_J once
dQ_I = Σ_J dQ_I_from_J
CUDA SCALAR ATOMIC INTERFACE
old = atomicAdd(address, value) atomically: old = *address *address = old + value return old
  • FA1/FA2 的 call site 丢弃返回值；每个 FP32 element 单独更新；
  • atomicity 防止 lost update，所以是 race-safe；
  • 不同 CTA 的 arrival/association order 没有固定；
  • (a+b)+c ≠ a+(b+c)，所以 bits 可变化。
owner ledger：one CTA J → complete dK_J,dV_J；many CTA J → partials of one dQ_I。
atomic 的“一个地址”是一个 scalar element；vector wrapper 最终展开成多个 scalar FP32 atomicsFA2 backward audit · CUDA atomic functions

FA1 → FA2 · CTA schedule

最重要的变化：让一个 CTA 直接拥有一块 Q → O

FA1 audited source: fix K/V tile j visit several small Q tiles i hand partial O/LSE state through GMEM FA2 forward: fix one larger Q tile i scan all valid K/V tiles j keep (m,l,O) with the owner

FA1 → FA2 · forward warp partition

数学区别：切 reduction axis 要相加；切 output rows 只需拼接

FA1 · FORWARDsplit B_N
O = Σ_w P[:,J_w] V[J_w,:]

warps 切 PV 的 reduction axis，都会产生同一 O rows 的 partial；CTA 内必须做 floating-point sum。

FA2 · FORWARDsplit B_M
O[I_w,:] = P[I_w,:] V
