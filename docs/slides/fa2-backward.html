Backward advantages over FA1 · mechanism, not slogans

1 · Larger Q work

64-row d128 tile amortizes fixed K/V state over fewer Q-loop iterations。

2 · Better warp ownership

all five representative GEMMs split output dimensions；no local dQ reduction tree。

3 · More CTA parallelism

one J CTA per K/V tile exposes 64 work units per head in the example。

4 · Better movement

cp.async and double buffering support the larger live state and overlap windows。

these improvements coexist with, rather than eliminate, the atomic protocolAdvantages
Non-Tensor-Core work · less, but not the same simplification as forward

Removed / amortized

  • 8-way local dQ: about 16×128×7=14,336 FP32 adds per FA1 tile；
  • partial-dQ shared stores/reloads；
  • local barrier/dependency；

  • the same five mathematical GEMMs。

Atomic guarantee

each read-modify-write is indivisible；no contribution is silently lost。

Missing guarantee

source does not impose ((a+b)+c) rather than (a+(b+c)) across independently scheduled CTAs。

FP32 addition is not associative；different legal arrival orders may produce different low bits。

atomicity is a memory correctness property, not a numerical-order contractAtomic

Implementation guidance · reusable beyond attention

1 · Prefer output owners

若有足够 output macrotiles，沿 free/output axis 分工；沿 reduction axis 分工会创建 combine obligation。

2 · Score every fused GEMM

同一轴在前一个 GEMM 可能是 output，在下一个 GEMM 可能是 reduction；不能只说“split K”。

3 · Count net resources

删除一个 64 KiB buffer 后，还要加上 larger Q/P/dS replacement buffers。

4 · Name sync scope

warp/CTA local reduction、cross-CTA atomic、kernel boundary 是三种不同成本与确定性问题。

5 · Keep four ledgers

compute、bytes/state、concurrency、protocol；storage saving 不自动等于 latency saving。

6 · Validate the chain

resolved specialization → resource metadata → ablation/profile → exact-output probe。

minimize numeric communication, not synchronization as an unqualified sloganGuidance
