Evidence and scope contract

Markdown is the source of truth. The notes separate mathematical facts, pinned-source observations, paper-reported measurements, hardware inference, and GPU validation still pending. “FlashAttention deterministic” is never used as a repository-wide boolean: the useful claim names forward/backward, backend, shape/mode, combine protocol, compiler artifact, device, and RNG state.

Large-head-dimension inference 现有一个明确标界的 forward extension；FlashMLA/paged-decode 的全 backend qualification、training backward、batch invariance 与 linear attention 仍未纳入核心 verdict。
