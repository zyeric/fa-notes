Online softmax · the three pieces of running row state

处理过一个 K/V prefix 后

m = max score seen so far ℓ = Σseen exp(Sⱼ − m) u = Σseen exp(Sⱼ − m) Vⱼ

partial output = u / ℓ

新 tile 到来时必须换坐标系

为什么这个 reduction 可重复？

  • later MMA 读取 previous accumulator；
  • compiled instruction stream 固定 D-chunk 次序；
  • WARPS_K=1，没有多个 warps 为同一 score 发布独立 D-partials；
  • warp 可暂停或与别的 warp interleave，但不能越过 true dependency。

这只支持固定 binary/architecture 的 repeatability；不证明 fused vs unfused、D64 vs D128、SM80 vs SM90 bits 相同。

Multi-head, varlen, and dropout · what changes?

Multi-head

每个 head 是独立 attention matrix；增加 grid CTAs，不引入 cross-head forward reduction。

v1.0.9 studied path expects equal Q/K/V head count；MQA/GQA outside scope。

Packed varlen

cu_seqlens 给 packed offsets；predicates / early exits 处理真实长度。

改变地址、active work 与 load balance；不改变 online recurrence 或 O-row owner。

Dropout

softmax 后对 P 应用 keep mask；normalizer 不变，value path 改变。

repeatability 额外要求 Philox seed、offset 与 logical-coordinate mapping 一致。

Probe 边界：padded / unused LSE bytes 不一定是 semantic output；fully masked rows 的约定也必须从 source 定义，不能直接把整个 workspace bytewise compare。

modes change dispatch and predicates more often than they change ownershipModes
Why fixed-plan FA1 forward repeats
1

Unique owner：每个 final O Q-row tile 只有一个 CTA writer。

2

Fixed contributor sequence：owner 按固定 K/V-tile order 更新 running state。

3

Fixed local trees：QK MMA、row max/sum、PV partial-O combine 都由 resolved kernel 固定。

4

No cross-CTA numeric combine：不同 CTA 写 disjoint O rows；没有 atomic accumulation。

5

Replay RNG：dropout 需要固定 logical Philox state。

scheduler 可以改变完成时间
但不能改变一个 O owner 内的 contributor order。

CTA A → O rows A CTA B → O rows B

running state 写 global 也不产生 race：仍只有原 owner CTA 按 program order 读写该地址。

What the verdict does—and does not—say
source-level conclusion

Expected bitwise repeatability

固定 input、RNG、shape/mode、num_splits、selected specialization、binary 与 hardware envelope 后，audited forward path 没有可见 cross-CTA numeric race。

source repeated-output race test 也支持 fixed-plan repeatability。

not implied

Cross-plan bits need not match

  • FA1 vs ordinary unfused attention；
  • 不同 B꜀ / D bucket / num_splits dispatch；
  • 不同 compiler artifact 或 architecture；
  • FA1 vs FA2/FA3/FA4；
  • workspace padding bytes；
  • 整个 training stack 的 end-to-end determinism。

两个 kernel 可以各自 deterministic，仍因为 reduction grouping 不同而产生不同 bits。

repeatability is conditional; equality across implementations is a stronger contractDeterminism
