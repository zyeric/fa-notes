FA3 → FA4 · human-memory model

先记四个动词：搬家、重排、减负、定序

MOVE

搬家

WGMMA accumulator 从 RMEM 搬到 tcgen05 TMEM。

省 accumulator registers；解除普通 register writeback dependency。

REORDER

重排

fully-async MMA、更大 tile、forward 多 softmax/correction roles、backward 跨 iteration overlap。

让更多 MMA 与非 MMA 工作同时 in flight。

REDUCE

减负

partial exp、conditional rescale、TMEM residence、2-CTA B staging、减少 dQ global updates。

扩 exp 吞吐，并削减 ALU、SMEM 与 reduction cost。

ORDER

定序

deterministic mode 用 semaphore 固定同一 destination 的 writer order。

只约束冲突 combine；有等待/fence 代价，普通 fast path 仍 nondeterministic。

根因：B200 Tensor Core ≈ 2×，SMEM / exp ≈ 1×不是让单个 GEMM magically 更快

Forward · partial software exp emulation

第二条 exp 生产线：range reduction + integer bits + FMA polynomial

一个 emulated element 怎么算

x = n + f, n = floor(x), f ∈ [0,1)
2ˣ = 2ⁿ · 2ᶠ
  1. clamp x ≥ −127，避免 underflow；
  2. round-down trick 得到整数部分 n；
  3. f = x − n；
  4. Horner FMA chain 近似 2ᶠ；
  5. 用 IEEE-754 exponent bits 构造 2ⁿ 并组合。
t = fma(f, p3, p2) t = fma(f, t, p1) t = fma(f, t, p0)

Forward · second algorithm change

另一部分 softmax cost：不是每个 K/V tile 都必须 rescale O_old

conditional rescale

if rowmax(Sj) - m_ref > τ: rescale O_old; update m_ref else: keep m_ref; accumulate under old scale
  • 最后用 true max / denominator normalize。
  • 旧 P 不回头改；当前 P tile 立即进入 P@V。
  • warp-uniform decision 避免 lane divergence。
