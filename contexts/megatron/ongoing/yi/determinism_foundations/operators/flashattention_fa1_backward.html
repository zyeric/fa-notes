Softmax Jacobian · why one row scalar D appears
dSᵢ = (diag(Pᵢ) − PᵢPᵢᵀ) dPᵢ Dᵢ = Pᵢᵀ dPᵢ = Σⱼ Pᵢⱼ dPᵢⱼ dSᵢⱼ = Pᵢⱼ (dPᵢⱼ − Dᵢ)

Interpretation

  1. dPᵢⱼ 是每个 probability element 收到的 gradient；
  2. Dᵢ 是整行共享的 weighted mean correction；
  3. 减掉 Dᵢ 保证 gradient respects softmax row coupling；
  4. 乘 Pᵢⱼ 后得到 scaled-score gradient dS。

dS 这里是对 scaled score S=τQKᵀ 的 gradient；τ 在 dQ/dK epilogue 中乘回。

Why not four warps?

  • backward 同时有 QK、dP、dQ、dK、dV 多个 matrix products；
  • chosen 8-way K slice 为 dQ 产生 8 份 partial，同时给 dK/dV 分出 disjoint output rows；
  • 更多 warps 增加 CTA 内 parallel work，也提高资源 footprint。

forward 128 threads 与 backward 256 threads 是两个独立编译的 kernels，不存在“一个 CTA 永远四个 warps”。

Why parallel mode can win—and why deterministic mode can be slower

Sequence-K parallel benefit

  • grid expands from B×H=32 CTAs to B×H×64=2048 CTAs；
  • D128 backward CTA is resource-heavy and likely one/SM；
  • more waves improve utilization and causal load balance；
  • each CTA owns one J, shortening its serial lifetime。

Protocol cost

  • separate D kernel；
  • zero FP32 dq_tmp；
  • atomic RMW contention and traffic；
  • final copy/cast kernel；
  • possible cache/interference differences。

所以 deterministic=True 的 slowdown 主要来自 减少 CTA parallelism；parallel mode 用 atomic protocol 换回更多 waves，但收益必须超过 contention 和 extra traffic。
